# FieldOps IT Frontend SPA

Aplikasi antarmuka web modern teknisi & admin inventori IT kantor ISP. Dibangun dengan React 19, Vite 8, Tailwind CSS v4, dan PWA offline-ready.

## Fitur UI
- Single Office Architecture: Nol pemilih workspace / database, satu kantor tunggal.
- Zero-Pill & Kontras Sesuai `docs/TEMA_DAN_DESAIN.md`.
- Autentikasi berbasis sesi server: tidak ada hash atau kata sandi di browser.
- PWA installable untuk smartphone teknisi lapangan.
